# AutoPaginate

AutoPaginate is a Chrome extension that helps users capture long and multi-page web content, organize it into a usable document, and export it as clean PDFs or images.

## Product

AutoPaginate is designed for people who need to save structured web content such as:

- research
- reports
- online documents
- tenders
- articles
- reference-heavy webpages

Key capabilities include:

- long webpage capture
- multi-page document capture
- document assembly
- editing and annotation
- PDF and image export
- reference and link preservation
- privacy-focused local-first processing
